# Changelog

## 0.2.2

- Remove orbits from all compound lettermarks, including LL and VN.
- Use the same upright 7×12 glyph grid, stroke width and rounded terminals for every letter.
- Use the palette's contrasting accent for secondary letters.
- Surround standalone V and P with a single orbit that never intersects the letter.

## 0.2.1

- Replace corner badges with full-height lettermarks: VH, VP, VL, LL, VN, VO and VI.
- Give project files a standalone P in the orbital style.
- Remove letter clipping masks and unify both orbit halves' geometry, thickness and gradient.

## 0.2.0

- Four reference-inspired palettes: Violet Orbit, Blue Orbit, Amber Orbit and Monochrome Orbit.
- V-and-orbit symbol with distinct geometric markers for core VIP file types.
- Automatic light and dark icon variants; grayscale across every icon in the monochrome theme.
- Offline preview with palette selection, background switching and extension search.

## 0.1.0

- Initial VIP file icon theme and extension mappings.
